## 🚀 How to Install and Run on macOS

### Step 1: Download the Application
Click the [**Download for macOS**](https://github.com/OjasCoder12/pixveda-macos/releases/latest/download/PixVeda-macOS.zip) button above to download `PixVeda-macOS.zip`.

---

### Step 2: Extract and Move to Applications
1. Open your **Downloads** folder.
2. Double-click `PixVeda-macOS.zip` to extract **`PixVeda.app`**.
3. Drag **`PixVeda.app`** into your **Applications** folder.

---

### Step 3: Launch PixVeda (First Time Gatekeeper)
Because PixVeda is distributed directly from GitHub and not the Mac App Store, macOS Gatekeeper may show a notification on first launch:

**Method A (Recommended):**
1. Open Finder and go to **Applications**.
2. **Right-click** (or `Control` + click) on **`PixVeda`**.
3. Select **Open** from the menu.
4. In the dialog box that appears, click **Open**.

**Method B (System Settings):**
1. If you see *"PixVeda cannot be opened because it is from an unidentified developer"*, click **Cancel**.
2. Open **System Settings** (or System Preferences).
3. Click **Privacy & Security** (or Security & Privacy).
4. Scroll down to the **Security** section.
5. Click **Open Anyway** next to the notification for PixVeda.

*(You only need to do this once. PixVeda will open normally afterwards).*

## ✨ About PixVeda

PixVeda is an all-in-one AI study companion designed specifically for school and college students:
- 🤖 **AI Chat Tutor:** Step-by-step concept explanations tailored to student grade and syllabus.
- 🗂️ **Interactive Flashcards:** Spaced-repetition study decks to master topics quickly.
- 🧠 **Mind Maps:** Visual diagrams and concept hierarchies generated on the fly.
- ⏱️ **Focus Sessions:** Dedicated study timer with integrated assistance.
- 📝 **Smart Notes & Summarizer:** Convert long documents and textbook chapters into key takeaways.
- 🎯 **Practice Quizzes:** Instant MCQs and test questions with real-time feedback.
- 📅 **Day Planner:** Timetable and guided weekly study plans.
